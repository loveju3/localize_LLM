# LLM 技術教學章節

本教材依專案實作分為五個部分、共 16 章。每條原始大綱已展開為獨立小節，包含概念、專案實作與限制；每章另附實作練習、結果判讀及程式碼連結。

建議依章節編號閱讀；閱讀前提為基本 Python、HTTP 與 SQL。第 1～3 章建立模型與架構概念，第 4～8 章完成 RAG 知識鏈，第 9～10 章介紹推論與評估，第 11～15 章深入微調，第 16 章整合實驗方法。

## 閱讀與實作方式

- 教材依 2026-10-06 檢視的程式碼整理。歷史實測數值另連結既有紀錄，不代表目前雲端服務狀態，也不是本次重新執行的結果。
- 程式碼中的設定值是本專案實驗起點，不是所有模型或資料的通用最佳值。線上官方文件可能更新，實際重現以專案固定套件版本與程式碼為準。
- Shell 命令與 Python 範例的相對路徑，以專案根目錄為工作目錄。`tokenizer` 沿用範例會註明建立方式；首次模型下載、資料庫連線及 GPU 執行需完成各自前置設定。
- 可先做不連雲端的公式計算、PDF 解析、資料檢查與回答驗證。下載模型需要網路，GPU 訓練、載入或推論可能產生成本，各章另行標示。
- `data/` 中的報告與訓練產物通常不隨 Git 提供；新 checkout 可先閱讀連結的驗證紀錄。教學用假設文件與數值不應當成已完成的品質評估。
- OCR、混合檢索、reranker 與 QLoRA 會以延伸方向說明，沒有把它們列為現成功能。

各章內的「程式碼與延伸閱讀」可用來核對函式與實作；章末練習重點是能解釋結果及限制，而非只得到成功訊息。

## 程式碼與閱讀版面

相關小節採「詳細解說 → 專案原碼節錄 → 閱讀重點」排列。每段標明檔案、函式或設定區塊、原始行號，並提供原檔與起始行連結。純理論、歷史結果與尚未實作功能會明確說明界線，不以示意碼充當現有原碼。

程式碼使用獨立的 fenced code block（Python／SQL），不塞入表格、巢狀清單或 HTML 折疊區塊。相對縮排與原始換行保留，語法上色取決於 Markdown 檢視器支援；單段只摘錄相關的數行至十多行，方便對照說明。

長行仍保留原碼，不為排版任意拆字串或修改邏輯。窄視窗中是否橫向捲動或視覺折行，由檢視器決定；Markdown 本身不能保證所有軟體採同一版面。若以純文字開啟，會看到三個反引號，但縮排仍然存在；閱讀排版後的內容可使用檢視器的 Markdown 預覽模式。

節錄依 2026-10-06 工作區內容產生，不會隨原始碼自動更新；行號可能在後續修改後移動。原檔連結採用專案相對路徑，行號使用 GitHub 的 #L 錨點；不支援行號錨點的本機檢視器可改點旁邊原檔連結，依函式名稱尋找。搬移整份專案不需更改路徑。

## 模組呼叫時序圖

16 章各附一張以程式碼為主的 Mermaid `sequenceDiagram`，放在第一個詳細小節前。泳道標示檔案、類別或函式，例如 `app/main.py`、`service.py / RagService`、`db.py / Repository`；第三方套件與遠端服務會明確區分。

實線箭頭列出函式與輸入參數，虛線箭頭列出回傳型態、主要欄位或例外。例如 `Inference.answer(question, sources, model)` 回傳 `(raw_answer, usage)`；`validate_answer(raw, sources)` 才回傳帶 `citations` 的結果。自我箭頭表示模組內部操作，沒有虛構跨模組呼叫。

`alt` 是條件分支，`opt` 是條件執行，`loop` 是重複呼叫。檔案產生、API 提交、背景訓練與狀態查詢可能屬不同時間的獨立執行，圖內另加註記。部分長參數以摘要表示，請搭配原碼節錄核對完整簽名。這些圖描述程式呼叫，不是可點擊的操作模擬器。

圖形需支援 Mermaid 的 Markdown 預覽器；不支援時顯示文字原碼。寬度、縮放及捲動由檢視器決定。圖下另附回傳資料解說，方便對照正文。
